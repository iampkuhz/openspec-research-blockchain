# 定义型 Primitive 写作规则

> 本文件来自已合并的 `write-primitive-definition` skill，降级为 `write-primitive-draft` 的参考子章节。

## 写作要点

- 形式化定义、关键术语、边界条件
- 定义应简洁（1-2句核心）
- 关键术语 3-7 个
- 边界条件清晰
- 前提条件列出
- 相关概念区分

## 质量保证

- 定义简洁准确
- 形式化描述正确（如适用）
- 所有 claims 都有 sources
- 术语与既有 glossary 一致，如有冲突则记录冲突和解决方式

## 失败模式处理

- 来源不足以下定义：标注 evidence gap，降低置信度
- 术语定义冲突：检查 glossary，记录冲突和解决方式
- 定义过于复杂：拆分为 definition + prerequisites
