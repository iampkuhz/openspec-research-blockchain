## 使用约束

- 报告用于理解背景、历史状态和推进节奏。
- 报告不能替代 `openspec/**`、`harness/workflows/**`、`harness/rules/**` 的正式约束。
- 若报告中的结论已上升为正式流程，应把正式规则写回 canonical 文档，并保持此目录只承担“状态快照”角色。
