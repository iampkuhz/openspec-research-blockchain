# 语言与写作风格

## 目的

定义本仓库的统一语言与写作约束。

## 要求

- 正文与模板默认**必须**中文优先维护。
- 协议名、标准名、字段名、EIP / ERC / RIP 编号与关键技术术语优先保留英文。
- 必需的系统标识符、artifact id、schema key、文件名可以保留英文。
- 分析与结论**不得**直接使用营销话术。
- glossary 层**必须**使用服务当前题目的术语列表写法，**不得**退化为随手附录。

## 数学公式书写规范

### 原则

**所有数学公式必须使用 LaTeX 语法（行内 `$...$` 或块级 `$$...$$`），不得使用 code block（\`\`\`）显示公式。**

### 理由

1. **可读性**：LaTeX 渲染后的公式更直观，符合数学阅读习惯
2. **语义正确**：code block 是等宽字体，用于代码而非数学
3. **渲染一致性**：LaTeX 在不同平台渲染效果一致

### 写法对比

| 场景 | ❌ 错误（code block） | ✅ 正确（LaTeX） |
|------|---------------------|-----------------|
| 行内公式 | `x*y=k` | `$x \cdot y = k$` |
| 块级公式 | ```\nA * n^n * Σx_i\n``` | `$$A \cdot n^n \cdot \sum{x_i}$$` |
| 分数 | `D / n` | `$$\frac{D}{n}$$` |
| 乘积 | `Πx_i` | `$$\prod{x_i}$$` |
| 求和 | `Σx_i` | `$$\sum{x_i}$$` |
| 幂次 | `D^(n+1)` | `$$D^{n+1}$$` |
| 趋近 | `A → ∞` | `$A \to \infty$` |
| 不等式 | `x_i ≈ x_j` | `$x_i \approx x_j$` |

### 常用 LaTeX 符号速查

| 含义 | LaTeX | 渲染效果 |
|------|-------|----------|
| 乘法 | `\cdot` | $\cdot$ |
| 除法 | `\frac{a}{b}` | $\frac{a}{b}$ |
| 幂 | `x^{n}` | $x^{n}$ |
| 下标 | `x_{i}` | $x_{i}$ |
| 求和 | `\sum{x_i}` | $\sum{x_i}$ |
| 乘积 | `\prod{x_i}` | $\prod{x_i}$ |
| 趋近 | `\to` | $\to$ |
| 约等 | `\approx` | $\approx$ |
| 无穷 | `\infty` | $\infty$ |
| 希腊字母 | `\alpha, \beta, \gamma` | $\alpha, \beta, \gamma$ |

### 块级公式示例

```markdown
✅ 正确写法：

StableSwap 不变量公式：

$$A \cdot n^n \cdot \sum{x_i} + D = A \cdot D \cdot n^n + \frac{D^{n+1}}{n^n \cdot \prod{x_i}}$$

其中：
- $A$ = Amplification Coefficient
- $n$ = 资产数量
- $x_i$ = 第 $i$ 个资产的储备量
- $D$ = 不变量（交易前后保持不变）
```
