# 表格规则

## 目的

规范表格的使用场景和格式。

## 何时使用表格

### 适用场景

1. **对比数据**
   - 多对象、多维度对比
   - 特性对比

2. **结构化信息**
   - 参数列表
   - 配置项

3. **映射关系**
   - 术语映射
   - 版本对应

### 不适用场景

1. **流程描述**
   - 用 Sequence Diagram

2. **关系展示**
   - 用 Component Diagram

3. **简单枚举**
   - 用列表

## 表格类型

### 类型 1: 对比表

```markdown
| 维度 | 方案 A | 方案 B | 方案 C |
|------|--------|--------|--------|
| 延迟 | 1s | 0.5s | 0.3s |
| 吞吐量 | 1000 TPS | 5000 TPS | 10000 TPS |
| 成熟度 | 高 | 中 | 低 |
```

### 类型 2: 参数表

```markdown
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| gasLimit | uint256 | - | Gas 上限 |
| nonce | uint256 | - | 防重放 |
```

### 类型 3: 映射表

```markdown
| ERC-4337 | L1 Transaction | 说明 |
|----------|---------------|------|
| sender | from | 发起方 |
| callData | data | 调用数据 |
```

## 表格格式

### 列对齐

| 内容类型 | 对齐 |
|----------|------|
| 文本 | 左对齐 |
| 数字 | 右对齐 |
| 短文本 | 居中 |

```markdown
| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| 文本 | 短 | 100 |
| 长文本 | 中 | 200 |
```

### 列宽

- 避免过宽（>30 字）
- 过宽则拆分列
- 或使用换行

### 表头

- 简洁明确
- 使用名词
- 避免过长

## 表格内容规范

### 单元格内容

**必须**：
- 简洁（<50 字）
- 一致格式
- 明确单位

**禁止**：
- 大段文字
- 模糊描述
- 缺失单位

### 空值处理

| 情况 | 表示 |
|------|------|
| 不适用 | `-` |
| 未知 | `?` |
| 可选 | `(optional)` |

### 跨行/跨列

**谨慎使用**，仅当必要时：

```markdown
| 类别 | 项目 | 说明 |
|------|------|------|
| 类别 A | 项目 1 | 说明 1 |
| ^ | 项目 2 | 说明 2 |
```

## 表格引用

### 文中引用

```markdown
如表 1 所示...
```

### 表格标题

```markdown
**表 1**: 方案对比。展示三种方案的核心差异。

| 维度 | 方案 A | 方案 B |
|------|--------|--------|
```

### 表格来源

```markdown
**表 1**: 数据来源：[EIP-4337](url)

| 参数 | 值 |
|------|-----|
```

## 表格与图的配合

### 何时用表

- 精确数值
- 多维度对比
- 配置参数

### 何时用图

- 关系展示
- 流程说明
- 趋势分析

### 配合使用

```markdown
图 1 展示架构，表 1 列出参数。

![图 1: 架构](...)

**表 1**: 组件参数

| 组件 | 参数 | 值 |
|------|------|-----|
```

## 复杂表格处理

### 拆分策略

当表格过大时：

1. **按维度拆分**
   ```
   原表：10 列 × 20 行
   → 表 1: 5 列 × 20 行（性能）
   → 表 2: 5 列 × 20 行（生态）
   ```

2. **按对象拆分**
   ```
   原表：10 列 × 20 行
   → 表 1: 10 列 × 10 行（方案 A/B）
   → 表 2: 10 列 × 10 行（方案 C/D）
   ```

3. **使用附录**
   ```markdown
   详见 [完整参数表](./appendix-params.md)。
   ```
