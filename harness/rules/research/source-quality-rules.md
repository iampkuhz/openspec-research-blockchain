# Source Quality Rules

## 来源分层

| 层级 | 类型 | 用途 |
|---|---|---|
| L1 | 官方规范/EIP/白皮书 | 核心技术主张 |
| L2 | 参考实现/官方文档 | 技术主张支持 |
| L3 | 官方博客/Release notes | 背景/动机 |
| L4 | 第三方分析/社区讨论 | 社区观点参考 |

## 质量要求

- 核心技术主张必须有 L1 或 L2 来源支撑
- L1 来源优先使用规范原文，而非解读文章
- L2 来源优先使用官方参考实现，而非第三方复刻
- L3/L4 来源必须标注置信度
- 来源之间冲突时优先采信 L1/L2
- 无法验证的链接必须标注原因

## 证据提取

- 摘录准确反映原文
- 区分原文引用和分析笔记
- 原文引用使用 blockquote 格式
- 记录来源的时效性（是否最新版本）

## 验证要求

- 每个来源必须尝试访问验证
- 无法访问时记录原因和替代方案
- 官方链接变更时更新为最新有效 URL
