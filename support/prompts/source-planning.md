# Prompt：来源规划

请为当前研究对象创建或改写 `plan.md` 中的“来源规划”部分。

## 输入

- 研究对象名称
- 研究层级
- 研究路径
- 当前问题
- 已知来源线索

## 任务

输出一个结构化的来源规划部分，至少包含：

- `L1`、`L2`、`L3`、`L4` 四层来源
- 每条来源的状态：`pending / read / needs verification`
- 每条来源在当前研究中的作用
- `evidence gaps`
- `unresolved ambiguities`

## 强约束

- 优先从 `L1/L2` 建立机制分析所需的最小证据集合
- 明确哪些只是线索，哪些已经可以作为主依据
- 如果当前只有 `L3/L4`，必须明确标红其局限
- 不要把链接堆砌成清单，要让来源与问题绑定
