# 场景决策资产

这里存放长期维护的场景决策资产。

这类资产不是纯技术分析本身，而是把：

- `knowledge/analysis/primitives/`
- `knowledge/analysis/synthesis/`
- `knowledge/analysis/domains/`

中的知识，应用到具体场景、约束和候选方案里，形成可复用的决策判断。

因此它与 `knowledge/analysis/` 共享仓库祖先，但不与 `primitive` 共享同一个直接父目录。

这里默认长期保留：

- `reference.md`
- `criteria.md`
- `dependencies.md`
- `glossary.md`
- `verdict.md`

这里不放：

- `request.md`
- `brief.md`
- `sources.md`
- `evidence-matrix.md`
- case 级 `README.md`
