# 长期产出资产

这里统一放仓库中的长期正式产出。

当前分为两类：

- `knowledge/analysis/`：长期事实分析资产
- `knowledge/decisions/`：长期场景决策资产

这层的作用是把“长期正式产出”与：

- `openspec/changes/` 的过程改动包
- `openspec/specs/` 的长期系统规约
- `skills/` 的 AI 协作技能

清楚分开。

这里默认只保留可长期复用的结果文件，不保留：

- `request.md`
- `plan.md`
- `draft.md`
- `evidence-matrix.md`
- case 级 `README.md`

术语层默认并入各对象的 `artifact.md`，作为其中的“关键术语”区，不再单独拆长期 `glossary.md`。
