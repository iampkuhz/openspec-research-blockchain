# 长期产出资产

这里统一放仓库中的长期正式产出。

当前分为两类：

- `knowledge/analysis/`：长期事实分析资产
- `knowledge/decisions/`：长期场景决策资产

这层的作用是把“长期正式产出”与：

- `openspec/changes/` 的过程改动包
- `openspec/specs/` 的长期系统规约
- `support/` 的支撑方法资产

清楚分开。

这里默认只保留可长期复用的结果文件，不保留：

- `analysis.md`
- `request.md`
- `brief.md`
- `sources.md`
- `evidence-matrix.md`
- case 级 `README.md`
