# Curve StableSwap AMM 机制分析

## 概述

Curve Finance 是第一个针对稳定币交易优化的去中心化交易所（DEX），其核心创新 StableSwap AMM 通过改进的不变量公式，实现了远低于传统 AMM 的滑点。

**核心问题**：为什么稳定币交易需要特殊的 AMM 设计？

传统 AMM（如 Uniswap）使用 x*y=k 不变量，价格曲线在整个范围内均匀分布。但稳定币的特性是价格始终围绕 1:1 小幅波动，这意味着 99% 的价格区间对稳定币交易毫无用处，流动性被分散到无效区间，导致有效区间滑点过高。

**StableSwap 的解决方案**：通过引入 Amplification Coefficient (A)，将流动性"集中"在 peg 附近，实现极低的滑点。

## 关键术语

| 术语 | 定义 | 作用 |
|------|------|------|
| AMM (Automated Market Maker) | 自动化做市商，通过数学公式而非订单簿定价 | Curve 的基础机制类型 |
| Invariant (不变量) | 交易前后保持不变的数学表达式 | StableSwap 的核心 |
| Slippage (滑点) | 实际成交价与预期价格的偏差 | StableSwap 优化的目标 |
| Amplification Coefficient (A) | 控制流动性集中程度的参数 | StableSwap 的关键设计 |
| Peg | 稳定币的目标价格（如 1 USD） | 汇率维持的基准 |
| LP Token | 流动性提供者凭证 | 费用分配和赎回机制 |
| Virtual Price | LP Token 的真实价值（含累积费用） | LP 退出时的价格基准 |

## StableSwap 不变量公式

### 公式推导

StableSwap 结合了两个不变量：

1. **恒定和公式**（极低滑点，但会耗尽流动性）：

   $$A \cdot n^n \cdot \sum{x_i} = D$$

2. **恒定积公式**（Uniswap，保证流动性不枯竭）：

   $$\prod{x_i} = \left(\frac{D}{n}\right)^n$$

**StableSwap 不变量**（结合两者）：

$$A \cdot n^n \cdot \sum{x_i} + D = A \cdot D \cdot n^n + \frac{D^{n+1}}{n^n \cdot \prod{x_i}}$$

其中：
- $A$ = Amplification Coefficient
- $n$ = 资产数量
- $x_i$ = 第 $i$ 个资产的储备量
- $D$ = 不变量（交易前后保持不变）

### 公式的直观理解

**当 $A \to 0$ 时**：公式退化为 $x \cdot y = k$（Uniswap）
**当 $A \to \infty$ 时**：公式趋近于恒定和（极低滑点）

**设计精妙之处**：
- 在 peg 附近（$x_i \approx x_j$），表现像恒定和，滑点极低
- 远离 peg 时，表现像恒定积，保证流动性不枯竭

## Amplification Coefficient 机制

### A 的作用

| A 值 | 流动性集中度 | 滑点特性 | 风险 |
|------|-------------|---------|------|
| $A = 1$ | 均匀分布 | 滑点较高 | 安全性高 |
| $A = 100$ | 中度集中 | 滑点中等 | 中等风险 |
| $A = 10000$ | 高度集中 | 滑点极低 | 脱 peg 风险高 |

**关系链**：$A$ 值大小 → 流动性集中度 → 滑点特性 → 风险特征

### A 值的选择

| A 值 | 适用场景 | 滑点特性 | 风险 |
|------|----------|----------|------|
| 1-10 | 弱相关资产 | 接近 Uniswap | 低 |
| 50-200 | 稳定币对（如 3pool） | 低滑点 | 中 |
| 1000+ | 高度相关资产（如 stETH/ETH） | 极低滑点 | 高（脱 peg 时） |

**Trade-off**：
- A 值越高 → peg 附近滑点越低 → 但脱 peg 时流动性枯竭越快
- A 值越低 → 流动性分布越均匀 → 但 peg 附近滑点优势不明显

## 汇率维持原理

### Peg 的数学基础

StableSwap **不直接维持 peg**，而是通过：

1. **套利机制**：当市场价格偏离时，套利者会进行交易使价格回归
2. **流动性集中**：在 peg 附近的高流动性使小额套利有利可图

### 价格发现机制

$$\text{内部价格} = f(\text{储备比例}, A)$$

$$\text{外部价格} = \text{市场供需}$$

当 $\text{内部价格} \neq \text{外部价格}$ 时：
- 套利机会出现
- 套利者交易直到价格一致

### 是否依赖预言机？

**答案：否**。Curve StableSwap 是纯 AMM 机制：

| 机制 | 是否依赖预言机 | 说明 |
|------|---------------|------|
| 价格发现 | 否 | 由储备比例和 A 值决定 |
| 汇率计算 | 否 | 纯数学公式 |
| 清算机制 | 否 | 依赖套利者，无强制清算 |

## LP Token 机制

### LP Token 铸造

对于多资产池，LP Token 的铸造公式：

$$\text{minted} = \text{totalSupply} \times \frac{\text{depositAmount}}{\max(\text{reserves})}$$

**与两资产池的差异**：
- Uniswap：$\sqrt{x \cdot y}$ 计算
- Curve：考虑 $n$ 个资产的相对比例

### 费用累积和分配

$$\text{费用累积} \to \text{增加池子总储备} \to \text{Virtual Price} \uparrow \to \text{LP Token} \uparrow$$

| 步骤 | 说明 |
|------|------|
| 1. 用户存入资产 | 获得 LP Token |
| 2. 交易发生 | 费用留在池内 |
| 3. 池子储备增加 | Virtual Price 上升 |
| 4. LP 赎回 | 按比例获得增值后的资产 |

### Virtual Price

$$\text{Virtual Price} = \frac{\text{总储备价值}}{\text{LP Token 总量}}$$

- 初始值：$1.0$
- 随时间增长（因为有交易费用累积）
- LP 退出时的实际兑换比率

## 与 Uniswap 对比

### 不变量对比

| 特性 | Uniswap (x*y=k) | Curve (StableSwap) |
|------|-----------------|-------------------|
| 不变量形式 | 简单乘积 | 混合公式 |
| 参数 | 无 | A (Amplification) |
| 流动性分布 | 均匀 | 集中在 peg 附近 |
| 小额滑点 | 高 | 极低 |
| 大额滑点 | 线性 | 非线性（先低后高） |

### 滑点曲线对比示意

```
滑点
  ↑
  │                    Uniswap (x*y=k)
  │                  /
  │                /
  │              /
  │            /
  │          /    StableSwap (A=100)
  │        /    __
  │      /   __
  │    / __
  │  /
  │/___________________→ 交易规模
  0
```

**解读**：
- 小额交易：StableSwap 滑点远低于 Uniswap
- 大额交易：两者趋同（因为都触及流动性边界）

### 能力归属

| 能力 | 协议原生 | 外部依赖 |
|------|----------|----------|
| 价格发现 | ✅ | ❌ |
| 汇率维持 | ✅ (数学 peg) | 套利者执行 |
| 流动性提供 | ✅ (池子机制) | LP 存入资产 |
| 费用分配 | ✅ (自动累积) | ❌ |
| 价格预言 | ❌ | 需要 Chainlink 等 |

## 设计取舍

### 为什么选择针对稳定币优化？

**问题**：为什么不直接用 Uniswap？

**答案**：稳定币市场有特殊需求：

| 因素 | 传统 AMM | StableSwap |
|------|----------|------------|
| 典型交易规模 | $1k-$100k | $100k-$10M+ |
| 可接受滑点 | < 0.5% | < 0.1% |
| 价格波动范围 | 任意 | ~1% 以内 |

**结论**：大额稳定币交易需要更低的滑点，StableSwap 通过牺牲通用性换取了效率。

### A 值的 Trade-off

| 维度 | 高 A 值 | 低 A 值 |
|------|--------|--------|
| 优势 | 极低滑点 | 脱 peg 时更安全 |
| 劣势 | 脱 peg 风险高 | 滑点优势不明显 |
| 适用 | USDC/USDT 等稳定币对 | 弱相关资产对 |

### 为什么不依赖预言机？

**设计选择**：纯 AMM，无预言机依赖

**原因**：
1. **抗审查性**：不依赖外部数据源
2. **抗操纵性**：预言机可能被操纵
3. **简洁性**：减少攻击面

**代价**：
- 无法主动维持 peg（依赖套利者）
- 极端情况下可能长期脱 peg

## 边界与前提

### 协议原生能力 vs 外部依赖

| 能力 | 来源 | 说明 |
|------|------|------|
| 价格计算 | 协议原生 | 由 AMM 公式决定 |
| peg 维持 | 外部（套利者） | 协议不主动维持 |
| 流动性深度 | LP 决定 | 协议只定义分配机制 |
| 费用参数 | 协议/DAO | 可配置 |

### 能力边界

**能解决**：
- 低滑点的稳定币交换
- 高效的资本利用率
- 被动的费用累积

**不能解决**：
- 主动维持 peg（需要套利者）
- 防止脱 peg（只能减轻影响）
- 无常损失保护（LP 仍面临 IL）

### 假设条件

1. **存在套利者**：市场有足够的套利资本
2. **资产确实稳定**：底层资产本身是"稳定"的
3. **无系统性风险**：没有大规模挤兑

## 结论

### 已确认结论

- StableSwap 使用混合不变量公式（结合恒定和与恒定积）
- A 值控制流动性集中程度：A 值越高，peg 附近流动性越集中，滑点越低
- Curve 不依赖外部预言机：价格发现由纯数学公式完成
- peg 附近滑点显著低于 Uniswap（小额交易尤为明显）
- LP 费用通过 Virtual Price 机制累积：费用留在池内，LP Token 升值

### 尚需验证

- 最优 A 值的选择策略（需要分析多个池子的实际运行数据）
- 极端行情下的行为（需要分析历史脱 peg 事件）
- 与理论滑点的实际偏差（需要链上数据验证）
