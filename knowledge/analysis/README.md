# 事实分析资产

这里存放长期维护的事实分析资产。

目录分层为：

- `knowledge/analysis/primitives/`
- `knowledge/analysis/synthesis/`
- `knowledge/analysis/domains/`

它们共同构成技术分析主链：

`primitive -> synthesis -> domain`

这里默认长期保留：

- `reference.md`
- `glossary.md`
- `dependencies.md`（仅 `synthesis / domain` 需要时保留）

这里不放：

- `request.md`
- `brief.md`
- `sources.md`
- `evidence-matrix.md`
- case 级 `README.md`
- 其他只服务当前一轮研究纠偏的过程文件

这些过程文件应进入 `openspec/changes/<change-name>/`。
