# OpenSpec Templates

本目录包含 OpenSpec change 的模板。

## Change 类型

| 类型 | 用途 | 模板目录 |
|------|------|----------|
| new-topic | 新增主题 | `new-topic/` |
| update-topic | 更新现有主题 | `update-topic/` |
| refactor-topic | 重构主题 | `refactor-topic/` |

## 使用流程

1. 确定 change 类型
2. 复制对应模板目录
3. 填充内容
4. 提交 OpenSpec

## 模板结构

每个类型包含：

- `proposal.md` - 变更提案
- `design.md` - 设计方案
- `tasks.md` - 任务分解
- `eval-plan.md` - 评估计划
- `specs/` - 具体规格定义
